# Theme System Usage Guide

## Color Palette

The app uses a modern, minimal color scheme with your specified colors:

- **Primary Brand**: #FCA311 (Amber/Orange)
- **Secondary Brand**: #14213D (Dark Navy)
- **Black**: #000000
- **Grays**: 
  - Light mode: #E5E5E5 (Light gray)
  - Dark mode: #D4D4D4 (Softer white, less eye strain)
- **White**: #FFFFFF (Light mode) / #E5E5E5 (Dark mode - softer)

## Available Color Classes

### Background

- `bg-bg-primary` - Main background
- `bg-bg-secondary` - Secondary background
- `bg-bg-tertiary` - Tertiary background
- `bg-bg-elevated` - Elevated surfaces
- `bg-bg-overlay` - Overlay backgrounds

### Surface

- `bg-surface-primary` - Primary surface
- `bg-surface-secondary` - Secondary surface
- `bg-surface-tertiary` - Tertiary surface
- `border-surface-border` - Default border
- `border-surface-border-hover` - Hover border

### Text

- `text-text-primary` - Primary text (90% white in dark mode for less eye strain)
- `text-text-secondary` - Secondary text
- `text-text-tertiary` - Tertiary text
- `text-text-disabled` - Disabled text
- `text-text-inverse` - Inverse text

### Accent Colors

- `bg-accent-primary` - Primary accent (#FCA311)
- `hover:bg-accent-primary-hover` - Primary hover
- `active:bg-accent-primary-active` - Primary active
- `bg-accent-secondary` - Secondary accent
- `hover:bg-accent-secondary-hover` - Secondary hover
- `active:bg-accent-secondary-active` - Secondary active

### Status Colors

- `bg-status-success` / `bg-status-success-light`
- `bg-status-warning` / `bg-status-warning-light`
- `bg-status-error` / `bg-status-error-light`
- `bg-status-info` / `bg-status-info-light`
